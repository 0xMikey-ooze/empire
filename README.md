# Bible Discovery

Explore biblical structures, sacred objects, and visions through interactive 3D exhibits grounded in Scripture.

## Discoveries

- Noah's Ark — Genesis 6–8
- The Ark of the Covenant — Exodus 25
- The Tabernacle — Exodus 25–40
- Solomon's Temple — 1 Kings 6–8
- Nebuchadnezzar's Dream Image — Daniel 2

Each exhibit includes a rotatable model, a Scripture-bounded inspection view, clickable learning points, cited explanations, a lesson, floor-plan or material study, artifacts, timeline, and quiz.

AI-assisted reconstructions are labeled throughout the experience. Biblical claims cite Scripture, while details Scripture does not specify are identified as illustrative.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
npm run lint
```

The biblical exhibit tests enforce the five-item discovery library and guard key accuracy decisions, including the ark's singular window-and-door wording, the Tabernacle board count, Solomon's Temple plan boundaries, and Daniel's image as a material study rather than an invented interior.
